# Chinese syllable audio attribution

Local single-character pronunciation uses pinyin syllable MP3 files copied from:

- https://github.com/hugolpz/audio-cmn/tree/master/64k/syllabs
- https://github.com/davinfifield/mp3-chinese-pinyin-sound

These files are used only for local educational pronunciation playback.
Sentence audio is generated separately through Google Cloud Text-to-Speech and cached under `web/audio/tts/chinese/`.
