# math_trainer

# 数学练习小助手

## Development

This project uses [mise](https://mise.jdx.dev/) to keep the Go and Node.js
toolchains consistent across machines.

```bash
mise install
mise run setup
mise run dev
```

Useful tasks:

- `mise run build` — build the server
- `mise run test` — run Go tests
- `mise run check` — run frontend regression checks
- `mise run verify` — run all tests and checks
